# Alpha 1.4.2 - The Debug Room

## Changed
- **File select:** choosing an empty file now starts a new game straight away in Haven Village, outside Gigglebuns' house. The list of starting areas is gone.
- **Pause menu:** the WARP option still works, but the debug menu now has a fuller warp list that also lets you pick the entrance.

## Added
- **DEBUG button** on the file select, under the three files. It starts an unsaved game in Haven with the debug menu open.
- **Debug menu.** Press F1 on keyboard, or hold BACK and press START on a controller, to open it anywhere during play. Switch tabs with LB / RB (Q / E on keyboard).
  - **WARP:** every area. Left/right picks which entrance you arrive at.
  - **CHEATS:** infinite health, infinite ammo, infinite coins, game speed (0.25x to 4x), refill health, kill all enemies, give everything, restart area, save to file.
  - **ITEMS:** turn each item on or off; set arrows, bombs, sword, shield and boots; turn the bun pieces on or off; set hearts, heart shards, coins and wallet size.
  - **STATE:** turn story flags on or off; for each dungeon, set cleared, keys, map, compass and boss key. Every other flag the file has set is listed too and can be turned off.
